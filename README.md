# Трекер жизни

Личное PWA-приложение: **трекер финансов** и **трекер дня** на общей базе — Google Таблицах.

Одно приложение, три входа — каждый ставится на экран «Домой» отдельной иконкой:

| Вход | Адрес | Что внутри |
| --- | --- | --- |
| Трекер жизни | `/life-tracker/` | «Сегодня» + день + финансы |
| Трекер финансов | `/life-tracker/finance/` | запись, история, статистика |
| Трекер дня | `/life-tracker/day/` | отметки дел цветом, планы, разовые дела, итоги и комментарий дня |

## Как устроено

- **Данные** живут в Google Таблице «Финансы». Сервер — Google Apps Script (код — в приватном репозитории `life-tracker-server`): принимает `POST {token, action, args}`, пишет строки, считает суммы в $ и ₾ по курсу Нацбанка Грузии на дату операции.
- **Приложение** (React + TypeScript + Vite) хранит копию данных и очередь на телефоне (IndexedDB). Запись сохраняется сразу, без сети — уходит в таблицу, когда появляется интернет (при открытии приложения, при событии `online`, повтор каждые 30 с при ошибке). У каждой записи свой `id`, повторная отправка не создаёт дублей.
- **Ключ** хранится только в «Свойствах скрипта» Apps Script и на устройстве; в коде его нет. Подключение на телефоне — ссылкой вида `…/finance/#k=<ключ>&u=<адрес скрипта>` (hash не уходит на сервер и сразу стирается из адресной строки).

## Трекер дня

Сервер — существующий скрипт таблицы «2026 Календарь + задачи». Рядом с `Code.gs` добавлен файл `Api.gs` (вход `doPost`; код — в приватном `life-tracker-server`), он вызывает те же функции (`getData`, `setColor`, `setComment`, разовые дела) и ничего в `Code.gs` не меняет. Старое развертывание продолжает работать.

- `days` — несколько дней одним запросом (выбранный и соседние).
- `apply` — очередь правок с телефона. Дело ищется по номеру строки **и** названию (строки сдвигаются); если ячейку успели поменять в другом месте, правка не затирает её (`conflict`).
- `struct` — дела, категории и пункты итогов (только онлайн: сдвигаются строки).
- `report` — сводка за период до 93 дней (`getReport`, вся аналитика на сервере); рисунки дня — только с `drawings: true`, для PDF.
- `history` — цвета всех строк до сегодняшнего дня и настроенные графики; `saveCharts` — сохранить графики (их видит и полная версия).
- `pdf` — `makeReportPdf`: PDF в папку «Трекер дня — отчёты» на Диске; картинки (тренд, рисунки) рисует приложение (`src/day/pdfImages.ts`).
- Открытые сводки и история хранятся на телефоне — без сети видно последнее загруженное.
- `goals` / `goalOps` / `goalsExport` — цели (лист «Цели»). У цели постоянный id, поэтому правки копятся в очереди без сети; новые цели получают id на телефоне (`apiGoalAdd_`, повтор не создаёт дубль). Остальные правки — те же `renameGoal`, `setGoalStatus`, `reorderGoals`, `deleteGoal`… Выгрузка PDF/TXT — `exportGoals`, только онлайн.
- `saveStates` — состояния (цвета отметок), только онлайн; проверки — в `saveStates` Code.gs. Уже отмеченные ячейки не перекрашиваются.
- Рисунки дня (лист «Рисунки»): приходят вместе с днём в `days`, сохраняются правкой `drawing` в той же очереди `apply` (→ `saveDrawing`), поэтому работают без сети. В очереди хранится только последняя версия каждого рисунка.
- Всё из полной версии трекера теперь есть и в приложении.

Приглашение для дня — `#dk=<ключ>&du=<адрес>`; для «Трекера жизни» можно объединить: `#k=…&u=…&dk=…&du=…`.

## Связи и выгрузки

- **Трекер жизни**: на вкладке «День» — «Деньги за день» (записи финансов этой даты), в «Сводке» — «Деньги за период». Трекер дня сам о финансах не знает: это вставки (`DayExtras`) из `src/life/Money.tsx`.
- **Бюджеты** (финансы): месячный лимит на верхнюю категорию приобретений, хранится в настройках таблицы (`budgets`, `budgetCur`). Карточка в статистике за месяц и подсказка в форме записи.
- **Excel**: `src/core/xlsx.ts` — свой писатель .xlsx без зависимостей (zip без сжатия + XML). Финансы → История → кнопка выгрузки.
- **Перетаскивание**: `src/core/reorder.tsx` (`useReorder`) — дела, категории, цели.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/life-tracker/
npm test
npm run build
```

Публикация — GitHub Actions → GitHub Pages при пуше в `main`.

## Сервер

Код обоих проектов Apps Script — в приватном репозитории `life-tracker-server` (там же — как развернуть с нуля и как выкладывать). Ключ API задаётся в «Свойствах скрипта» (`API_TOKEN`).

## Публикация

- **Приложение (этот репозиторий, публичный)**: `git push` в `main` → GitHub Actions: тесты, сборка, GitHub Pages. На телефоне новая версия включается сама при следующем открытии (сервис-воркер с `skipWaiting`, проверка обновлений при возвращении в приложение).
- **Сервер (Apps Script)** — приватный репозиторий `life-tracker-server`, выкладка с Мака через clasp: `npm run pull` → правка → `npm run deploy:day` / `deploy:finance`. Подробности — в его README.
- В этом репозитории нет ни ключей, ни адресов скриптов, ни данных: всё это вводится на телефоне (приглашение) или приходит с сервера после подключения.
